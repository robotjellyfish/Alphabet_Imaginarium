Generate display text in a cool artistic ransom note style!
##### This tool generates decorative text by replacing typed letters with a scramble of randomly styled unicode characters that look visually similar.

### ! PLEASE READ BEFORE COPYING ! 
## Generated text is for decorative use only—and should not be used as a substitute for readable text. Visually similar glyphs are different Unicode characters therefore software and screen readers can treat them differently, pronounce them unpredictably, or fail to display them at all. Keep names, instructions, and accessibility-critical text in ordinary readable characters.
